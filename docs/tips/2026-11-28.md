## 한국어 — Drawing 캐시의 상태 의존성 분리

11월 28일 공식 Compose 그룹 목록의 최신 발표는 11월 18일이며 최근 24시간 신규 그룹 릴리스는 없다. 개별 커밋과 최신 BOM은 미확인.

drawWithCache에서 Brush를 생성하고 매 프레임 바뀌는 alpha는 onDrawBehind에서 읽는다. 캐시 생성 블록에서 alpha.value를 읽으면 값 변경에 따라 캐시가 무효화될 수 있다. 크기와 다른 캐시 의존성이 동일할 때 Drawing 단계에서만 alpha를 읽으면 Brush를 재사용할 수 있다.

재사용 가능한 전체 Composable (Activity 제외):

```kotlin
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.size
import androidx.compose.runtime.Composable
import androidx.compose.runtime.State
import androidx.compose.ui.Modifier
import androidx.compose.ui.draw.drawWithCache
import androidx.compose.ui.graphics.Brush
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp

@Composable
fun CachedGradient(alpha: State<Float>) {
    Box(Modifier.size(160.dp, 80.dp).drawWithCache {
        val brush = Brush.horizontalGradient(listOf(Color.Blue, Color.Cyan))
        onDrawBehind {
            drawRect(brush, alpha = alpha.value.coerceIn(0f, 1f))
        }
    })
}
```

검증: 동일 State 객체를 전달하고 alpha를 변경한다. 비교군에서는 alpha.value를 캐시 블록에서 읽는다. 캐시 생성 횟수와 할당량, 프레임 시간을 별도로 비교하고 동일 alpha에서 스크린샷을 검증한다. 크기 변경 후 캐시 갱신도 확인한다. 캐시할 객체가 없으면 drawBehind를 고려한다.

UI/Foundation/Runtime 핵심 API 1.0.0 stable 이상. 참조 1.13.0, 빌드 미실행. API 자체의 별도 AGP 최소 요건 없음. Runtime 1.12 alpha 릴리스는 API 37 및 AGP 9.2 최소 요건, 1.13 beta01은 Kotlin compiler 2.2 요구사항을 명시한다. 정확한 조합은 AAR metadata 및 compileSdk 지원표 확인 필요. Kotlin 2.x 대응 Compose Compiler Plugin, JDK는 AGP에 종속. 실험적 opt-in 및 AGP 9.5 전용 기능 없음. 빌드, 테스트, 성능 측정 미실행.

## English — Separate drawing cache dependencies from animated state

On November 28 the official Compose group index lists November 18 as the latest release date; no new group release in the preceding 24 hours. Individual commits and latest BOM identifier remain unverified.

Create the Brush in drawWithCache and read animated alpha inside onDrawBehind. Reading alpha.value during cache construction can invalidate the cache on changes. Reading it only during drawing permits reuse when size and other cache dependencies remain unchanged.

Complete reusable composable (not an Activity):

```kotlin
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.size
import androidx.compose.runtime.Composable
import androidx.compose.runtime.State
import androidx.compose.ui.Modifier
import androidx.compose.ui.draw.drawWithCache
import androidx.compose.ui.graphics.Brush
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp

@Composable
fun CachedGradient(alpha: State<Float>) {
    Box(Modifier.size(160.dp, 80.dp).drawWithCache {
        val brush = Brush.horizontalGradient(listOf(Color.Blue, Color.Cyan))
        onDrawBehind {
            drawRect(brush, alpha = alpha.value.coerceIn(0f, 1f))
        }
    })
}
```

Verification: pass the same State object and change alpha. As a control read alpha.value during cache construction. Compare cache construction counts, allocations and frame timing separately; compare screenshots at equal alpha and verify cache updates after resizing. Consider drawBehind when no objects need caching.
