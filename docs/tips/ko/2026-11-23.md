## 릴리스 확인 (2026-11-23, Asia/Seoul)

**공식 릴리스 목록에서 최근 24시간(2026-11-22~2026-11-23) 동안 새로 발표된 Compose 그룹 릴리스를 찾지 못했습니다.** 이 확인으로는 AndroidX 소스에 개별 커밋이 반영되었는지 알 수 없습니다. 목록의 최신 릴리스 날짜는 2026-11-18입니다. Compose UI/Foundation/Runtime/Animation의 최신 버전은 각각 1.13.0 안정 버전과 1.14.0-alpha01이며, Material3는 1.5.0 안정 버전과 1.6.0-alpha01입니다. 도구, UI 테스트, 접근성 및 BOM 배포 관련 변경 사항을 별도로 모두 확인하지는 않았습니다.

Foundation 1.13.0에는 개정된 테두리 렌더러(beta02)와 윤곽선 경계의 일관성을 바로잡는 수정 사항(rc01)이 포함됩니다. 업그레이드할 때는 특히 둥근 가장자리와 직사각형 이외의 도형을 스크린샷으로 검토하세요. Runtime 1.13에는 Kotlin 컴파일러 2.2가 필요합니다. [Foundation 릴리스 노트](https://developer.android.com/jetpack/androidx/releases/compose-foundation) · [Runtime 릴리스 노트](https://developer.android.com/jetpack/androidx/releases/compose-runtime) · [릴리스 목록](https://developer.android.com/jetpack/androidx/versions)

## 실무 팁 — 테두리 렌더링 변경의 영향 확인하기

**문제.** Compose 업그레이드 후 스크린샷의 픽셀 차이가 발생하면 컴포넌트 측정값, 타이포그래피, 패딩 외에 테두리 구현 변경도 원인일 수 있습니다. Foundation 1.13 beta02는 새 테두리 구현을 도입하고 둥근 직사각형의 윤곽선을 수정했습니다. 1.13 rc01에서는 테두리 렌더링을 윤곽선 크기에 맞췄습니다.

**방법.** 크기, 선 두께, 색상을 고정한 조건에서 직사각형과 모서리가 둥근 도형을 렌더링합니다. 예제는 재사용 가능한 완전한 컴포저블 함수입니다. Activity나 스크린샷 자동화 테스트는 별도로 구성해야 합니다.

```kotlin
import androidx.compose.foundation.border
import androidx.compose.foundation.layout.Arrangement
import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.Spacer
import androidx.compose.foundation.layout.size
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp

@Composable
fun BorderRegressionSamples() {
    Column(verticalArrangement = Arrangement.spacedBy(16.dp)) {
        Spacer(
            Modifier
                .size(96.dp, 48.dp)
                .border(1.dp, Color.Black)
        )
        Spacer(
            Modifier
                .size(96.dp, 48.dp)
                .border(2.dp, Color.Black, RoundedCornerShape(12.dp))
        )
        Spacer(
            Modifier
                .size(96.dp, 48.dp)
                .border(4.dp, Color.Black, RoundedCornerShape(24.dp))
        )
    }
}
```

**재현, 디버깅 및 검토**

- [ ] 기존 버전에서 기준 이미지를, Foundation 1.13.0에서 비교 이미지를 캡처합니다. 기기 또는 에뮬레이터, 화면 밀도, 글꼴 배율, 테마 및 렌더링 설정은 동일하게 유지합니다.
- [ ] 이미지를 크게 확대해서 둥근 모서리와 테두리 선의 정렬을 확인합니다. 윤곽선과 레이아웃 크기 중 어느 쪽이 바뀌었는지 구분합니다.
- [ ] 차이의 원인을 Foundation으로 판단하기 전에 호출부의 수정자 순서와 상위 레이아웃의 클리핑을 확인합니다.
- [ ] 픽셀 비교에서 안티앨리어싱 허용 오차를 명시합니다. 전체 픽셀 점수 외에도 특정 가장자리에서 발생한 차이를 조사합니다.
- [ ] 스크린샷 차이를 비교하고 영향을 받는 실제 OEM 컴포넌트의 도형을 테스트합니다. 이전 이미지의 모든 픽셀이 동일하게 유지된다고 가정하지 않습니다.
- [ ] 릴리스 노트에 언급된 기능 플래그를 임시로 조사한다면 선택한 아티팩트에서 해당 플래그에 접근할 수 있는지와 제거 정책을 확인합니다. 영구적인 호환성 보장으로 삼지 않습니다.
- [ ] 새 렌더러의 성능이 개선되었는지 판단하려면 벤치마크를 실행합니다.

## 버전 및 도구 체인 범위

| 항목 | 범위 |
| --- | --- |
| API 최초 제공 | `Modifier.border`는 Compose Foundation 1.0.0 계열부터 제공됩니다. |
| 예제 기준 | Foundation/UI 1.13.0 안정 버전(2026-11-18). 당시 Material3의 안정 버전은 1.5.0입니다. 예제에는 Material3 API가 필요하지 않습니다. |
| AGP 및 compileSdk | API 자체에는 별도 AGP 최소 요건이 없습니다. Foundation 릴리스 노트(2026-09-09 alpha03)는 Compose 라이브러리가 **compileSdk 37.1**로 전환했으므로 소비자 프로젝트도 전이 의존성의 요구사항에 맞춰 업데이트해야 한다고 명시합니다. AGP 9.2에서 공식 지원하는 최댓값은 **API 37.0**이므로 AGP 9.2가 37.1의 요구사항을 충족한다고 가정하지 마세요. 공식 호환성 정보에서 해당 SDK를 지원하는 AGP를 찾고 해석된 AAR 메타데이터를 확인하세요. 이번 검토에서는 호환되는 상위 AGP의 최소 버전을 확인하지 못했습니다. |
| Kotlin / 컴파일러 | Compose 1.13 beta01에는 **kotlinc 2.2**가 필요합니다. Kotlin 2.x에서는 해당 버전에 맞는 `org.jetbrains.kotlin.plugin.compose`를 적용합니다. |
| Gradle / JDK | 선택한 호환 AGP에 따라 달라집니다. 참고로 AGP 9.2 문서는 Gradle 9.4.1과 JDK 17을 최소 버전으로 명시합니다. AGP 9.2와 compileSdk 37.1의 호환성은 검증되지 않았습니다. |
| 실험적 기능 | 옵트인과 AGP 9.5+의 실험적 테스트 스위트 기능은 사용하지 않습니다. |
| 검증 | 공식 문서만 검토했습니다. Gradle 빌드, 스크린샷 계측 테스트, 접근성 검사 및 성능 벤치마크는 **실행하지 않았습니다**. |
