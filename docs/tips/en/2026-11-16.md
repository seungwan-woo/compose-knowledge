## 1. Use `derivedStateOf` to update a Boolean from frequently changing scroll state

The scroll offset in pixels changes frequently. Whether to show a back-to-top button depends only on whether the first visible item index is zero or greater than zero.

~~~kotlin
import androidx.compose.foundation.lazy.LazyColumn
import androidx.compose.foundation.lazy.items
import androidx.compose.foundation.lazy.rememberLazyListState
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.runtime.derivedStateOf
import androidx.compose.runtime.getValue
import androidx.compose.runtime.remember

@Composable
fun ShowTopStatus() {
    val listState = rememberLazyListState()
    val showTopButton by remember(listState) {
        derivedStateOf { listState.firstVisibleItemIndex > 0 }
    }

    // Button/AnimatedVisibility의 표시 조건으로도 사용할 수 있습니다.
    Text(if (showTopButton) "맨 위로 이동 가능" else "목록 첫 항목")
    LazyColumn(state = listState) {
        items((1..100).toList()) { index ->
            Text("Item $index")
        }
    }
}
~~~

**Intent.** Read changing inputs and update subscribed UI only when the resulting Boolean changes. `derivedStateOf` caches its result. Wrapping inexpensive operations such as simple string concatenation can add unnecessary overhead. The example uses text in place of a button to illustrate the behavior.

**Code review.** Check that `remember` uses the correct key, that the `derivedStateOf` calculation avoids state writes, and that the Composition actually observes `showTopButton`.

**Version scope.** `derivedStateOf` is available in `androidx.compose.runtime:runtime:1.0.0+`. `LazyColumn` requires Foundation, and `Text` requires Material3. The API has no separate AGP minimum. Projects adopting Compose 1.12.0 or later require **AGP 9.0+ and compileSdk 37**.

**Official references.** [Runtime API](https://developer.android.com/reference/kotlin/androidx/compose/runtime/package-summary) · [Compose performance best practices](https://developer.android.com/develop/ui/compose/performance/bestpractices)

## 2. Manage library versions with the Compose BOM and configure the Compiler separately

The earlier briefing used `alias(libs.plugins.kotlin.compose)` and `implementation(platform(...))` for projects with a version catalog. The snippets below show a standalone **partial configuration**.

Example `gradle/libs.versions.toml` entry. Pin the versions to the combination your project uses.

~~~toml
[versions]
kotlin = "2.2.20"
composeBom = "2026.09.00"

[plugins]
kotlin-compose = { id = "org.jetbrains.kotlin.plugin.compose", version.ref = "kotlin" }

[libraries]
androidx-compose-bom = { module = "androidx.compose:compose-bom", version.ref = "composeBom" }
~~~

Example excerpt from the module's `build.gradle.kts`.

~~~kotlin
plugins {
    // Android 및 Kotlin 플러그인은 프로젝트 설정에 따라 별도 선언.
    alias(libs.plugins.kotlin.compose)
}

android {
    buildFeatures { compose = true }
}

dependencies {
    val composeBom = platform(libs.androidx.compose.bom)
    implementation(composeBom)
    androidTestImplementation(composeBom)

    implementation("androidx.compose.ui:ui")
    implementation("androidx.compose.foundation:foundation")
    implementation("androidx.compose.material3:material3")

    androidTestImplementation("androidx.compose.ui:ui-test-junit4")
}
~~~

The Compose BOM coordinates versions across groups of Compose libraries. The Compose Compiler has its own plugin. With Kotlin 2.0 or later, use the same version for the `org.jetbrains.kotlin.plugin.compose` plugin and Kotlin. A BOM update leaves your Kotlin, Compiler, and AGP versions to their own configuration.

**Version scope.** BOM `2026.09.00` is the example version shown in the official documentation. Check artifact versions individually to establish which are current as of this date. The example uses `kotlin = "2.2.20"` for illustration, so check Kotlin and AGP compatibility for your project. AGP is managed separately from the BOM. Compose 1.12.0+ libraries require **AGP 9.0+ and compileSdk 37**. For Compose 1.13, also check the release notes for Kotlin compiler requirements. **Verification.** The example configuration has yet to be verified through a Gradle sync or build.

**Official references.** [BOM guide](https://developer.android.com/develop/ui/compose/bom) · [BOM mapping](https://developer.android.com/develop/ui/compose/bom/bom-mapping) · [Compose Compiler and AGP requirements](https://developer.android.com/develop/ui/compose/setup-compose-dependencies-and-compiler)
