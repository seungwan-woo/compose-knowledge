## English — Read draw-only state in the drawing phase

The official Compose group index on November 27 lists November 18 as the latest release date. UI/Foundation/Runtime/Animation/Material 1.13.0 stable and 1.14.0-alpha01; Material3 1.5.0 stable and 1.6.0-alpha01. No new group release identified in the preceding 24 hours. Individual commits, tooling, accessibility, tests and latest BOM identifier remain unverified.

For a color-only change, read State inside drawBehind rather than composition. A change to that observed state invalidates drawing without requiring composition or layout due to that read alone. Other invalidations may still occur. This does not replace layout or semantics updates when needed.

Complete reusable composable (not an Activity):

```kotlin
import androidx.compose.foundation.layout.Box
import androidx.compose.foundation.layout.size
import androidx.compose.runtime.Composable
import androidx.compose.runtime.State
import androidx.compose.ui.Modifier
import androidx.compose.ui.draw.drawBehind
import androidx.compose.ui.graphics.Color
import androidx.compose.ui.unit.dp

@Composable
fun ColorSwatch(color: State<Color>) {
    Box(Modifier.size(48.dp).drawBehind {
        drawRect(color.value)
    })
}
```

Pass the same State<Color> from the caller and change its value. Compare against reading color.value in composition and passing it to background. Compare Layout Inspector recomposition counts and Perfetto frame timing separately; verify screenshots at identical colors. Isolate unrelated state reads.
