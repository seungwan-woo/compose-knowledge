      ## Practical tip: isolate border rendering changes

      **Problem.** A pixel-diff regression after a Compose upgrade may be caused by a changed border implementation rather than a component's measurement, typography or padding. Foundation 1.13 beta02 introduced a new border implementation and fixes for rounded-rectangle outlines; 1.13 rc01 aligned border rendering with outline size.

      **Approach.** Render a controlled sample of rectangles and rounded corners at a fixed size, width and color. This is a complete reusable composable function, not a complete Activity or automated screenshot test.

      ```kotlin
      import androidx.compose.foundation.border
      import androidx.compose.foundation.layout.Arrangement
      import androidx.compose.foundation.layout.Column
      import androidx.compose.foundation.layout.Spacer
      import androidx.compose.foundation.layout.size
      import androidx.compose.foundation.shape.RoundedCornerShape
      import androidx.compose.runtime.Composable
      import androidx.compose.ui.Modifier
      import androidx.compose.ui.graphics.Color
      import androidx.compose.ui.unit.dp

      @Composable
      fun BorderRegressionSamples() {
          Column(verticalArrangement = Arrangement.spacedBy(16.dp)) {
              Spacer(
                  Modifier
                      .size(96.dp, 48.dp)
                      .border(1.dp, Color.Black)
              )
              Spacer(
                  Modifier
                      .size(96.dp, 48.dp)
                      .border(2.dp, Color.Black, RoundedCornerShape(12.dp))
              )
              Spacer(
                  Modifier
                      .size(96.dp, 48.dp)
                      .border(4.dp, Color.Black, RoundedCornerShape(24.dp))
              )
          }
      }
      ```

      **Reproduce / debug / review**

      - [ ] Capture a golden image on the existing version and a candidate image on Foundation 1.13.0 using the same device/emulator, density, font scale, theme, and rendering configuration.
      - [ ] Inspect rounded corners and border stroke alignment at high zoom; distinguish a changed outline from a changed layout size.
      - [ ] Review the call-site modifier order and parent clipping before attributing a mismatch to Foundation.
      - [ ] Keep anti-aliasing tolerances explicit in pixel comparisons; investigate localized edge mismatches rather than declaring a global pixel score sufficient.
      - [ ] Compare screenshot diffs and test actual affected OEM component shapes; this article does not claim that all previous images should remain pixel-identical.
      - [ ] If temporarily investigating feature flags mentioned in release notes, verify their accessibility and removal policy in the exact selected artifact; do not rely on flags as a permanent compatibility contract.
      - [ ] Benchmark before claiming a performance improvement from the new renderer.
