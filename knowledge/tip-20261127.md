      ## 한국어 — Drawing 단계에서 상태 읽기

      11월 27일 공식 Compose 목록의 최신 릴리스는 11월 18일이다. UI/Foundation/Runtime/Animation/Material 1.13.0 stable 및 1.14.0-alpha01, Material3 1.5.0 stable 및 1.6.0-alpha01. 최근 24시간 신규 그룹 릴리스는 확인되지 않았다. 개별 커밋, tooling, 접근성, 테스트 및 BOM 최신 식별자는 미확인이다.

      색상만 변경되는 경우 State 값을 Composition에서 미리 읽지 말고 drawBehind 내부에서 읽는다. 해당 읽기에 의한 변경은 Drawing을 무효화하며, 다른 invalidation이 없다면 Composition과 Layout을 다시 실행할 필요가 없다. 크기나 Semantics가 달라지는 경우에는 이 기법만으로 충분하지 않다.

      재사용 가능한 Composable 전체(Activity 제외):

      ```kotlin
      import androidx.compose.foundation.layout.Box
      import androidx.compose.foundation.layout.size
      import androidx.compose.runtime.Composable
      import androidx.compose.runtime.State
      import androidx.compose.ui.Modifier
      import androidx.compose.ui.draw.drawBehind
      import androidx.compose.ui.graphics.Color
      import androidx.compose.ui.unit.dp

      @Composable
      fun ColorSwatch(color: State<Color>) {
          Box(Modifier.size(48.dp).drawBehind {
              drawRect(color.value)
          })
      }
      ```

      상위 호출자는 동일한 State<Color>를 전달하고 값을 변경한다. 비교군은 Composition에서 color.value를 읽고 background에 전달한다. Layout Inspector의 재구성 횟수와 Perfetto 프레임 시간을 별도로 비교하고 동일 색상의 스크린샷을 검증한다. 다른 상태 읽기가 결과에 영향을 주지 않도록 한다.

      핵심 API는 UI/Foundation/Runtime 1.0.0 stable부터. 참조 버전 1.13.0, 빌드 미실행. API 자체의 별도 AGP 최소 요건이나 실험적 opt-in은 없다. Runtime 1.12 alpha 릴리스는 API 37 및 AGP 9.2 최소 요건을 명시했고 Material 1.13 개발 릴리스는 compileSdk 37.1 및 Kotlin compiler 2.2를 명시했다. 정확한 1.13 조합은 AAR metadata와 AGP 지원표로 확인해야 한다. Kotlin 2.x는 대응 Compose Compiler Plugin 사용, JDK는 AGP 요구사항에 종속. AGP 9.5 전용 기능 없음. 빌드, 테스트, 성능 측정 미실행.
